# ADINK CREW Furniture — Website

Website statis untuk ADINK CREW Furniture, Brebes, Jawa Tengah.

## Isi folder
- `index.html` — struktur halaman dan konten website
- `styles.css` — desain responsif
- `script.js` — menu mobile, tahun footer, dan formulir konsultasi WhatsApp
- `assets/favicon.svg` — ikon website

## Cara unggah ke GitHub
1. Buka repositori GitHub yang sudah dibuat.
2. Klik **Add file → Upload files**.
3. Unggah `index.html`, `styles.css`, dan `script.js`, serta folder `assets` beserta `favicon.svg`.
4. Klik **Commit changes**.
